# Модуль employee.bonuses

Тестовый модуль для начисления бонусов сотрудникам в системе «1С-Битрикс».

## Описание
Модуль предоставляет функционал для начисления бонусов сотрудникам за определенные действия или достижения, а также возможности ручного начисления через API. Встроенные обработчики позволяют автоматически начислять бонусы, например, при успешном закрытии сделок в CRM.

## Возможности
- **Таблица бонусов (ORM):** Хранит историю начисления бонусов (`b_employee_bonus`) с указанием сотрудника, суммы, причины и источника начисления.
- **Интеграция с CRM:** Автоматическое начисление бонусов (1% от суммы) ответственному сотруднику при успешном закрытии сделки (стадия `WON`). Защита от двойного начисления за одну и ту же сделку.
- **REST API:** Поддержка метода `bonuses.gettotal` для получения общей суммы бонусов по ID сотрудника.
- **Пользовательский интерфейс (UI):** Компонент грида (вкладка «Мои бонусы» в левом меню) для отображения истории начислений авторизованного пользователя с пагинацией и расчетом итоговой суммы.
- **Кастомное левое меню:** Модуль автоматически добавляет пункт «Мои бонусы» (`/bonuses/`) в левое меню корпоративного портала.

## Требования
- 1С-Битрикс: Корпоративный портал (с модулями `crm`, `rest`).
- PHP 8.0+

## Установка
1. Скопируйте папку модуля `employee.bonuses` в директорию `/local/modules/` (или `/bitrix/modules/`).
2. Перейдите в административный раздел сайта: Настройки -> Настройки продукта -> Модули.
3. Найдите в списке модуль «Модуль начисления бонусов сотрудникам» (`employee.bonuses`) и нажмите «Установить».
4. При установке модуль автоматически:
   - Создаст таблицу `b_employee_bonus` в базе данных.
   - Зарегистрирует необходимые обработчики событий (для CRM и REST).
   - Скопирует публичные файлы в папку `/bonuses/`.
   - Добавит пункт меню в левое меню интранета.

## Использование / API

### PHP API
Вы можете начислять бонусы вручную через класс `BonusService`:

```php
use EmployeeBonuses\BonusService;

try {
    $bonusId = BonusService::accrue(
        userId: 1, // ID сотрудника
        amount: 1500.50, // Сумма бонуса
        reason: 'За отличную работу в марте', // Причина
        sourceType: 'MANUAL', // Тип источника (по умолчанию 'MANUAL')
        sourceId: null, // ID сущности источника (например, ID сделки)
        createdBy: 1 // Кто начислил (опционально)
    );
    echo "Бонус начислен. ID записи: $bonusId";
} catch (\RuntimeException $e) {
    echo "Ошибка начисления: " . $e->getMessage();
}
```

Получение суммы бонусов пользователя:
```php
$total = BonusService::getTotalByUser(1);
```

### REST API
Метод `bonuses.gettotal` возвращает общую сумму бонусов сотрудника.

**Параметры:**
- `employee_id` (int) - ID сотрудника.

**Пример запроса:**
```
/rest/bonuses.gettotal?employee_id=1
```

**Пример ответа:**
```json
{
    "result": {
        "total": 1500.50
    }
}
```

## Удаление модуля
При удалении модуля через административный интерфейс:
- Будет удалена таблица `b_employee_bonus`.
- Будут удалены обработчики событий.
- Будет удалена папка `/bonuses/`.
- Пункт меню будет убран.
